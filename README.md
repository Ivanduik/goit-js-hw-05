# GoIT JavaScript Homework 05

Чотири задачі на перебираючі методи масивів JavaScript.

- `js/task-1.js` — `map()` для отримання імен користувачів.
- `js/task-2.js` — `filter()` та `includes()` для пошуку друзів.
- `js/task-3.js` — `toSorted()` для сортування за кількістю друзів.
- `js/task-4.js` — `filter()` і `reduce()` для підрахунку балансів.

## Перевірка

Відкрийте `index.html` у сучасному браузері, потім DevTools → Console.
У консолі з'являться результати всіх перевірочних викликів із завдання.
Метод `toSorted()` потребує сучасного браузера.

## Публікація

У GitHub: Settings → Pages → Build and deployment → Deploy from a branch →
`main` / `(root)` → Save. Посилання на сторінку має формат
`https://USERNAME.github.io/goit-js-hw-05/`.
